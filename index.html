使い方

はじめに（操作の流れ）

  1. 画面上部のドロップゾーン（または下の映像エリア）へ動画をドロップするか、ゾーンをクリックしてファイルを選択します（詳細は「ドロップゾーン（動画の読み込み）」）。
  2. トランスポートの Video で Side by Side / Difference / Overlay、Loop で終端後のループ有無、Auto Play で左右がそろったときの自動再生、Audio で Both / Older Only / Newer Only / Mute を選びます。
  3. Play / Pause とシークバー、またはキーボード（ページ中段のショートカット一覧）で再生位置を調整します。動画の同期ズレは Playback Drift 行で確認できます。
  4. トランスポート最下行の Export でモードと With TC を選び、Exp WebM でブラウザ内録画の WebM をダウンロードします。書き出し中のオーバレイや Esc キャンセル、出力ファイルの扱いは「書き出し（Exp WebM）とファイルについて」を参照してください。

ドロップゾーン（動画の読み込み）

  • 画面上部のドロップゾーンは、比較したい動画を読み込む入口です。ここへドロップするか、クリックしてファイルを選択できます。下の映像エリア（左・右パネル）へドロップしても読み込めます。ページ上のその他の領域へドロップした場合も、動画として扱えるファイルだけが読み込み対象です。
  • 動画はこのブラウザ内でのみデコード・再生され、サーバーへはアップロードされません。
  • 対応形式はブラウザが再生できる動画のみです。Google Chrome の利用を推奨します。
  • 左右の割り当て（ドロップゾーン・ファイル選択）：ファイルの最終更新日時で判定し、古い方を左・新しい方を右に並べます（同一時刻のときはファイル名順）。２本まとめて選ぶ／ドロップしたときに適用されます。
  • 左右の割り当て（映像エリアへ１本ずつ）：左パネルまたは右パネルへ１本ずつドロップした場合は、ドロップした側のまま配置します（更新日時による並べ替えはしません）。

動画の読み込みと左右の割り当て

  • ドロップゾーンをクリックするとファイル選択が開きます。ドロップゾーン・映像エリア・ページ上のその他の領域へ、いずれもドラッグ＆ドロップで読み込めます。
  • 動画を２本まとめて選ぶ／ドロップした場合（ドロップゾーンまたはファイル選択）：OS の最終更新日時が古いほうを左、新しいほうを右に並べます。同一時刻のときはファイル名順です。
  • ドロップゾーン等へ１本ずつ読み込む場合：空いている側（先に左、次に右）へ順に入ります。２本目を入れた時点で、更新日時に基づき左右が並べ替えられることがあります（上記「ドロップゾーン」の割り当てルール参照）。
  • 映像エリアの左・右パネルへ１本ずつドロップした場合：それぞれドロップしたパネル側に配置し、更新日時による並べ替えは行いません。
  • すでに左右がそろったあと、ドロップゾーン等から別ファイルを１本だけ追加すると、左だけ差し替えされ、右は未読み込みに戻ります。
  • セッションの自動復元（ブラウザの再読み込み時に保存データから左右の動画を戻す）については「特記事項」を参照してください。リロード時はシーク位置を先頭に戻し、自動再生は行いません。

パネル情報・タイムコード・FPS

  • 各パネル直下の補足行には、最終更新日時、コンテナから読めたときの FPS、および尺が分かるときの総フレーム数（Total: … f）が出ます。FPS が取れない形式では FPS n/a (~60 est.) のように参考表示になります。
  • MP4 など ISO ベースのコンテナでは、先頭付近のメタデータから推定した平均フレームレートを FPS に使います。
  • 各パネル映像の隅のタイムコードオーバーレイは、その側の FPS に合わせた HH:MM:SS:FF です。
  • トランスポートの現在 / 総尺のタイムコード、キーボードのフレーム送り、および重ねビュー中央のタイムコードは、左右の表示 FPS の大きい方を整数化したマスター FPS に基づきます。

トランスポート（再生・シーク・各オプション）

  • トランスポート最下行の Export 欄では、プルダウンで書き出しモード（Compare PiP / Older only / Newer only）を選び、With TC で Compare 時のみタイムコードの左下焼き込みのオン・オフを切り替えます（Older / Newer のみでは焼き込み必須のため、オフにすると説明オーバレイが出てチェックはすぐオンに戻ります。閉じ方は OK・外側クリック・Esc）。Exp WebM を押すと、Audio 行で選んだモードに応じた音声をミックスした WebM を録画します（Mute 選択時や Web Audio が使えない場合は映像のみ）。Both ミックスで書き出すときは左右のデコードが必要なため、片側エクスポートでも両方のファイルが読み込まれている必要があります。Compare 書き出しは左右そろっている必要があります。書き出し中は画面中央にオーバレイが出て操作がロックされ、Esc でキャンセルできる旨と進捗が表示されます。尺ぶんリアルタイムで進みます。出力形式の注意や MP4 / MJPEG への変換は「書き出し（Exp WebM）とファイルについて」を参照してください。Chrome 系の利用を推奨します。
  • 映像の下にあるトランスポート枠は、画面上から現在 / 総尺のタイムコード → シークバーと Play / Pause → Playback Drift →（１行下のオプション条）Video → Loop / Auto Play → Audio → Export の順で並んでいます。オプション条の詳細は、このあとの見出しどおりです。
  • シークバーの最大値（総尺）は、左右のうち長い方の尺に合わせます。表示中の現在位置は、両方の再生位置の遅い方（大きい方）に合わせて更新されます。
  • シークバーをドラッグしている間は、その値に応じて両方の動画へ同時にシークします。離したあと、再生中であれば更新ループが続きます。

同期、Playback Drift、自動補正

  • 同期の意味：シークや再生では、原則として両方の再生位置を同じ目標値に揃えます。デコードと描画はブラウザ任せのため、報告値がフレーム単位で常に一致するとは限りません。
  • トランスポートの Playback Drift 行は、左右の再生位置の差をミリ秒とマスター FPS 換算のフレーム数で示します。色分けは目安で、０に近いほど緑系、大きいほど赤系になります。いずれかが終端に達したときは ---- 表示になります。
  • 再生中にズレが約 100ms を超えた場合、短いクールダウンを挟みつつ、両方をマスター側の時刻に合わせて約１フレーム分だけ前進させる自動補正が入ります。尺の短い側が終端に張り付き、長い側だけが進んでいるときの差は同期不良とみなさず、補正しません。
  • 補正が走ると、ログに Sync auto-correct: … が間欠的に残ります。
  • Difference モードの見え方と同期の関係は、下の「映像レイアウト（Video）」の Difference を参照してください。Playback Drift の表示や自動補正は、重ね表示を読みやすく保つための目安・調整です。

映像レイアウト（Video）

  • トランスポート内の Video プルダウン、または [V] で、次の３モードだけをこの順に循環します。Side by Side（左右並び）→ Difference（差分重ね）→ Overlay（新しい側を上に、不透明度およそ 75% で重ねる）→ 先頭へ戻る、の繰り返しです。プルダウンの値と [V] は常に連動します。
  • Side by Side：左が古い動画、右が新しい動画の２パネル表示（既定）。ファイル名・補足行・隅のタイムコードの意味は、上の「パネル情報・タイムコード・FPS」と同じです。
  • Difference（差分重ね）：同一タイムライン上の２本を１画面に重ね、CSS の mix-blend-mode: difference で画素ごとに差を取ります。下層が左（古い方）、上層が右（新しい方）です。左右パネルは隠れ、合成ビューだけが表示されます。
  • Difference の見え方：２本の画素が一致している領域では差分がゼロとなり、画面は真っ黒に見えます。差異が無い区間では、黒い画面がそのまま続きます。左右で内容が違う箇所だけが、差分として色味の付いた表示で浮かび上がります。
  • Difference と同期ズレ（Playback Drift）：この見え方は「同一時刻の同じフレーム同士」を重ねている前提に強く依存します。Playback Drift のフレーム表示が 1 以上 のとき、実際には差の無い静止画でも、前後のフレームが少しずれて重なることで差分が出て、差が無いように見えるべき場所まで色が付いて見えることがあります。ズレを抑えたいときは、一度一時停止してから1 フレームだけシーク（キーボードの [←] / [→]）すると改善する場合があります。上の「同期、Playback Drift、自動補正」もあわせて参照してください。
  • Difference では、圧縮ノイズ・解像度差・トリミングのズレがあると、実質同じ内容でも差が広がって見えることがあります（ブラウザの合成に依存します）。
  • Overlay（オーバーレイ）：同じく２本を１画面に重ねます。下が左（古い方）、上が右（新しい方）です。上層（新しい側）に opacity: 0.75（およそ 75% 不透明）を当て、通常合成で下の画に重ねます。２本を半透明に重ねて目視比較するモードで、Difference のように一致領域が黒一色になることはありません。左右パネルは隠れ、合成ビューだけが表示されます。
  • Difference / Overlay の重ねモードでは、中央のタイムコードオーバーレイはトランスポートと同じマスター FPS（上記「パネル情報」）で、Side by Side 時より大きめの字体です。レイアウト切り替えは再生中でも可で、通常は再生が継続します。

ループ再生（Loop）

  • Loop にチェックが入っているとき（既定）：長い方の尺の終端に達すると、両方の再生位置を先頭付近へ戻し、再生を継続します（ブラウザ標準のループ属性ではなく、アプリ側で両者を揃えて再開しています）。
  • チェックを外したとき：終端で一時停止し、トランスポートが止まります。
  • On / Off はトランスポートのチェックボックスか [L] です。

自動再生（Auto Play）

  • Auto Play にチェックが入っているとき（既定）：ドロップまたはファイル選択で左右の動画がそろって再生可能になったタイミングで、自動的に再生を開始します（２本まとめて読み込んだとき、２本目を追加したときを含みます）。
  • チェックを外したとき：左右がそろっても自動では再生せず、Play ボタンまたは [Space] で開始します。
  • On / Off はトランスポートのチェックボックスか [A] です。設定は次回開いたときに復元されます。ブラウザの再読み込みやセッション復元時には自動再生しません（シーク位置は先頭のまま）。

音声出力（Audio）

  • トランスポートのラジオボタン、または [B] / [O] / [N] / [M] で切り替えます。ログや一時ヒントには内部的な説明が出ることがありますが、UI ラベルは Both、Older Only、Newer Only、Mute です。
  • Both：各動画の L/R をモノラル化し、古い方を L・新しい方を R にパンして出力します。
  • Older Only：左（古い方）のステレオをそのまま L/R に出力します。
  • Newer Only：右（新しい方）のステレオをそのまま L/R に出力します。
  • Mute：無音です。WebM 書き出し時も映像のみになります。

書き出し（Exp WebM）とファイルについて

  • 本アプリの Exp WebM は、ブラウザの録画機能と Web Audio で得た音声（Mute 時は映像のみ）を組み合わせて、WebM（主に VP8 / VP9 系＋必要に応じて Opus）をその場で生成しダウンロードします。編集・納品の現場では MP4（H.264 等）や MJPEG など別形式に慣れている方も多く、WebM 単体では馴染みが薄い形式かもしれません。
  • MP4 や MJPEG など別コンテナへ変換したい場合は、お手数ですがご利用の OS 向けの動画変換ツールやエンコーダを別途ご用意ください。本ページはサーバーにアップロードせずブラウザ内だけで完結するアプリであり、ブラウザが直接書き出せる形式に出力が限られることは仕様です。
  • WebM を他形式へ再エンコードするとき、色空間・ガンマ・レンジ（limited / full 等）の扱いをツール側で誤ると、結果が意図より暗くなったりコントラストがずれたりすることがあります。変換プリセットや「色の管理」「レンジ」の項目は、利用するソフトのマニュアルで確認してください。

シーク・操作の画面上ヒント

  • 矢印キーやテンキーのジャンプ、レイアウト / 音声 / ループの変更などのあと、画面上部に短いテキストのフラッシュが出ることがあります。ログとあわせて、直近の操作内容の確認に使えます。

キーボードショートカット

  • 再生・シーク・音声・レイアウト・ループなどにショートカットがあります。内容はページ中段のショートカット一覧どおりです。
  • 無効になるフォーカス：textarea、select（Video のプルダウン含む）、input のうちシークバー以外、ならびに contenteditable 要素にフォーカスがある間は、ショートカットは処理されません。シークバーにフォーカスがある場合は、主要なショートカットキーを押すとフォーカスが外れてから処理されます。
  • 矢印キーは連打リピート時もシークに使えます。その他の多くのキーはリピートを無視します。
