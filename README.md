## 特記事項

- 本ページは**無償で提供される実験的なウェブアプリ**です。不具合を常時監視しておらず、ご利用中に問題が生じても原則として把握いたしません。あらかじめご了承のうえご利用ください。
- 動画は**このブラウザ内でのみ**デコード・再生され、サーバーへは**いかなる情報もアップロードされません**。**Google Chrome** の利用を推奨します。ブラウザや形式によってはデコードできないことがあります。
- このページの **HTML・CSS・JavaScript** は目的を問わず**自由に改変・複製・再利用**して構いません（商用・社内ツールを含みます）。連絡も不要です。独自版を公開・配布する場合、フッターのコピーライト表記とリンクは**削除しても構いません**（未改変の配布では残すことを推奨しますが、フォークや大幅なカスタマイズでは必須ではありません）。
- 本アプリは静的ファイル（`index.html`・`css/`・`js/` など）で構成されています。**ビルドやサーバーは不要**です。フォルダごと保存し、ルートの `index.html` をブラウザで開いてください（`file://` で動作します。favicon 等の外部 CDN 参照は環境により取得できない場合があります）。
- ディスク上の元ファイルを書き出し直した場合でも、本アプリは**自動では再読み込みしません**。更新した動画を反映するには、**ドロップゾーン**または**映像エリア**へ再度ドロップしてください。前回セッションの復元はブラウザ内の保存データ（`IndexedDB`）に保存されたコピーを参照します（元ファイルのパスは保持しません）。ブラウザのストレージ整理により保存データが消えると、セッションは復元できません。
- **Video** / **Audio** / **Export** / **Loop** / **Auto Play** などの UI 設定は、次回開いたときにブラウザ内（`localStorage` 等）から復元されます。**Speed** は保存されず、ページの**再読み込み**時は常に **1x** です。シークバー位置は保存されず、再読み込み時は常に先頭です。読み込んだ動画データのコピーもブラウザ内（`IndexedDB` 等）に保存されます。
- 書き出しファイルはブラウザ標準の **WebM** です。MP4 / MJPEG 等への変換や色の扱いは「使い方」の「**書き出し（Exp WebM）とファイルについて**」を参照してください。

## 使い方

### はじめに（操作の流れ）

1. 画面上部の**ドロップゾーン**（または下の**映像エリア**）へ動画をドロップするか、ゾーンを**クリックしてファイルを選択**します（詳細は「**ドロップゾーン（動画の読み込み）**」）。
2. **Play** / **Pause** とシークバー、またはキーボード（ページ中段の**キーボードショートカット**）で再生位置を調整します（**Play/Stop** は [`Space`]）。動画の同期ズレは **Playback Drift** 行で確認できます（**Auto Play** が ON のときは、左右がそろうと自動的に再生が始まることもあります）。
3. トランスポートの **1 段目**で **Video**（**Side by Side** / **Difference** / **Overlay**）、**Audio**（**Both** / **Older Only** / **Newer Only** / **Mute**）、**Export** を選びます。**2 段目**で **Speed** と **Loop**・**Auto Play** を調整します（詳細は各見出しを参照）。
4. トランスポート **1 段目**の **Export** でモードと **With TC** を選び、**Exp WebM** でブラウザ内録画の WebM をダウンロードします。書き出し中のオーバレイや `Esc` キャンセル、出力ファイルの扱いは「**書き出し（Exp WebM）とファイルについて**」を参照してください。

### ドロップゾーン（動画の読み込み）

- 画面上部の**ドロップゾーン**は、比較したい動画を読み込む入口です。**ここへドロップ**するか、**クリックしてファイルを選択**できます。下の**映像エリア（左・右パネル）**へドロップしても読み込めます。ページ上のその他の領域へドロップした場合も、動画として扱えるファイルだけが読み込み対象です。
- 動画は**このブラウザ内でのみ**デコード・再生され、サーバーへは**アップロードされません**。
- 対応形式は**ブラウザが再生できる動画**のみです。**Google Chrome** の利用を推奨します。
- **左右の割り当て（ドロップゾーン・ファイル選択）**：**ファイルの最終更新日時**で判定し、**古い方を左・新しい方を右**に並べます（同一時刻のときはファイル名順）。２本まとめて選ぶ／ドロップしたときに適用されます。
- **左右の割り当て（映像エリアへ１本ずつ）**：左パネルまたは右パネルへ**１本ずつ**ドロップした場合は、**ドロップした側のまま**配置します（更新日時による並べ替えはしません）。

### 動画の読み込みと左右の割り当て

- ドロップゾーンを**クリック**するとファイル選択が開きます。ドロップゾーン・映像エリア・ページ上のその他の領域へ、いずれもドラッグ＆ドロップで読み込めます。
- 動画を**２本まとめて**選ぶ／ドロップした場合（ドロップゾーンまたはファイル選択）：**最終更新日時**が古いほうを**左**、新しいほうを**右**に並べます。同一時刻のときはファイル名順です。
- ドロップゾーン等へ**１本ずつ**読み込む場合：空いている側（**先に左、次に右**）へ順に入ります。２本目を入れた時点で、更新日時に基づき左右が並べ替えられることがあります（上記「ドロップゾーン」の割り当てルール参照）。
- **映像エリアの左・右パネル**へ１本ずつドロップした場合：それぞれ**ドロップしたパネル側**に配置し、更新日時による並べ替えは**行いません**。
- すでに左右がそろったあと、ドロップゾーン等から別ファイルを**１本だけ**追加すると、**左だけ差し替え**され、右は未読み込みに戻ります。
- セッションの自動復元（ブラウザの再読み込み時に保存データから左右の動画を戻す）については「**特記事項**」を参照してください。リロード時は再生位置を先頭に戻し、**Auto Play** による自動開始は行いません。

### パネル情報・タイムコード・FPS

- 各パネル直下の**補足行**には、**最終更新日時**、コンテナから読めたときの **FPS**、および尺が分かるときの**総フレーム数**（`Total: … f`）が出ます。FPS が取れない形式では `FPS n/a (~60 est.)` のように参考表示になります。
- **MP4** など ISO ベースのコンテナでは、先頭付近のメタデータから推定した平均フレームレートを FPS に使います。
- 各パネル映像の隅の**タイムコードオーバーレイ**は、その側の FPS に合わせた **HH:MM:SS:FF** です。
- トランスポートの**現在 / 総尺**のタイムコード、キーボードの **Seek**（1f など）、および重ねビュー中央のタイムコードは、左右の表示 FPS の大きい方を整数化した**マスター FPS** に基づきます。

### Playback / Seek（トランスポート）

- 映像の下にある**トランスポート枠**は、画面上から**現在 / 総尺のタイムコード** → **シークバー**と **Play** / **Pause** → **Playback Drift** →（オプション条・**2 段**）**1 段目**：**Video** → **Audio** → **Export**。**2 段目**（中央寄せ）：**Speed** → **Loop** / **Auto Play** の順です。各オプションの詳細は、このあとの見出しどおりです。
- シークバーの**最大値（総尺）**は、左右のうち**長い方**の尺に合わせます。表示中の**現在位置**は、両方の再生位置の**遅い方（大きい方）**に合わせて更新されます。
- シークバーを**ドラッグ**している間は、その値に応じて**両方の動画へ同時に移動**します（画面上のヒントは **Scrub**）。離したあと、再生中であれば表示の更新が続きます。

### 同期、Playback Drift、自動補正

- **同期の意味**：**Seek** や **Playback** では、原則として**両方の再生位置を同じ目標値に揃えます**。デコードと描画はブラウザ任せのため、報告値がフレーム単位で**常に一致するとは限りません**。
- トランスポートの **Playback Drift** 行は、左右の再生位置の差を**ミリ秒**と**マスター FPS 換算のフレーム数**で示します。色分けは目安で、**０に近いほど緑系**、**大きいほど赤系**になります。いずれかが終端に達したときは `----` 表示になります。
- 再生中にズレが**約 100ms を超えた**場合、短いクールダウンを挟みつつ、両方をマスター側の時刻に合わせて**約１フレーム分だけ前進**させる**自動補正**が入ります。尺の短い側が終端に張り付き、長い側だけが進んでいるときの差は同期不良とみなさず、補正しません。
- 補正が走ると、ログに `Sync auto-correct: …` が間欠的に残ります。
- **Difference** モードの見え方と同期の関係は、下の「**Video**」の **Difference** を参照してください。**Playback Drift** の表示や自動補正は、重ね表示を読みやすく保つための目安・調整です。

### Video

- トランスポート **1 段目**の **Video** プルダウン、または **[V]** で、次の３モードだけをこの順に循環します。**Side by Side**（左右並び）→ **Difference**（差分重ね）→ **Overlay**（新しい側を上に、不透明度およそ 75% で重ねる）→ 先頭へ戻る、の繰り返しです。プルダウンの値と **[V]** は常に連動します。
- **Side by Side**：左が**古い**動画、右が**新しい**動画の２パネル表示（**既定**）。ファイル名・補足行・隅のタイムコードの意味は、上の「**パネル情報・タイムコード・FPS**」と同じです。
- **Difference（差分重ね）**：同一タイムライン上の２本を１画面に重ね、CSS の `mix-blend-mode: difference` で画素ごとに差を取ります。下層が左（古い方）、上層が右（新しい方）です。左右パネルは隠れ、合成ビューだけが表示されます。
- **Difference の見え方**：２本の画素が一致している領域では差分がゼロとなり、画面は**真っ黒**に見えます。差異が無い区間では、黒い画面がそのまま続きます。左右で内容が違う箇所だけが、差分として**色味の付いた表示**で浮かび上がります。
- **Difference と同期ズレ（Playback Drift）**：この見え方は「同一時刻の同じフレーム同士」を重ねている前提に強く依存します。Playback Drift のフレーム表示が **1 以上** のとき、実際には差の無い静止画でも、前後のフレームが少しずれて重なることで差分が出て、**差が無いように見えるべき場所まで色が付いて見える**ことがあります。ズレを抑えたいときは、一度 **Pause** してから **Seek**（1f、[←] / [→]）すると改善する場合があります。上の「同期、Playback Drift、自動補正」もあわせて参照してください。
- **Difference** では、**圧縮ノイズ・解像度差・トリミングのズレ**があると、実質同じ内容でも差が広がって見えることがあります（ブラウザの合成に依存します）。
- **Overlay（オーバーレイ）**：同じく２本を１画面に重ねます。下が左（古い方）、上が右（新しい方）です。上層（新しい側）に `opacity: 0.75`（およそ 75% 不透明）を当て、通常合成で下の画に重ねます。２本を半透明に重ねて目視比較するモードで、Difference のように一致領域が黒一色になることはありません。左右パネルは隠れ、合成ビューだけが表示されます。
- **Difference / Overlay** の重ねモードでは、中央の**タイムコードオーバーレイ**はトランスポートと同じ**マスター FPS**（上記「パネル情報」）で、**Side by Side** 時より大きめの字体です。**Video** の切り替えは**再生中でも可**で、通常は再生が継続します（画面上のヒントは **Layout**）。

### Audio

- トランスポート **1 段目**のラジオボタン、または **[B]** / **[O]** / **[N]** / **[M]** で切り替えます。ログや一時ヒントには内部的な説明が出ることがありますが、UI ラベルは **Both**、**Older Only**、**Newer Only**、**Mute** です。
- **Both**：各動画の L/R をモノラル化し、**古い方を L・新しい方を R** にパンして出力します（プレビュー再生時）。
- **Older Only**：左（**古い方**）のステレオをそのまま L/R に出力します。
- **Newer Only**：右（**新しい方**）のステレオをそのまま L/R に出力します。
- **Mute**：**無音**です。WebM 書き出し時も**映像のみ**になります。

### Speed

- トランスポート**2 段目**の **Speed** 欄で、左右の再生速度を**リアルタイム**に変えられます。中央には現在の倍率（例：**1x**、**0.5x**、**2x**）が表示されます。
- **−** / **＋** ボタン、またはキーボードの **Slower** / **Faster** / **Reset 1x**（下記「キーボードショートカット」）で**一段階ずつ**変更します。通常は **0.25x** 刻みで、**0.25x** より遅い側の先頭だけ **0.1x** です。範囲は **0.1x**（最大 10 倍スロー）～ **2x**（2 倍速）で、既定は **1x** です。
- **保存されません**。ページの**再読み込み**のたびに **1x** に戻ります。
- **Exp WebM** への反映はありません（常に **1.0×** 録画）。詳細は「**書き出し（Exp WebM）とファイルについて**」を参照してください。

### Loop

- **Loop** にチェックが入っているとき（**既定**）：長い方の尺の終端に達すると、**両方の再生位置を先頭付近へ戻し、再生を継続**します（ブラウザ標準のループ属性ではなく、アプリ側で両者を揃えて再開しています）。
- チェックを**外した**とき：終端で **Pause** し、トランスポートが止まります。
- On / Off はトランスポート **2 段目**のチェックボックスか **Loop On/Off [L]** です。

### Auto Play

- **Auto Play** にチェックが入っているとき（**既定**）：ドロップまたはファイル選択で**左右の動画がそろって再生可能になったタイミング**で、自動的に再生を開始します（２本まとめて読み込んだとき、２本目を追加したときを含みます）。
- チェックを**外した**とき：左右がそろっても自動では再生せず、**Play** または **Play/Stop [Space]** で開始します。
- On / Off はトランスポート **2 段目**のチェックボックスか **Auto Play On/Off [A]** です。設定は次回開いたときに復元されます。ブラウザの**再読み込み**やセッション復元時には **Auto Play** による自動開始は行いません（再生位置は先頭のまま）。

### 書き出し（Exp WebM）とファイルについて

- トランスポート **1 段目**の **Export** 欄で、プルダウンから書き出しモード（**Compare (PiP)** / **Older only** / **Newer only**）を選び、**With TC** で Compare 時のみタイムコードの左下焼き込みのオン・オフを切り替えます（Older / Newer のみでは**焼き込み必須**のため、オフにすると説明オーバレイが出てチェックはすぐオンに戻ります。閉じ方は **OK**・外側クリック・`Esc`）。**Exp WebM** を押すと、**Audio** 行で選んだモードに応じた音声をミックスした WebM を録画します（**Mute** 選択時や Web Audio が使えない場合は**映像のみ**）。**Both** ミックスで書き出すときは左右のデコードが必要なため、片側モードでも**両方のファイルが読み込まれている**必要があります。**Compare (PiP)** は**左右そろっている**必要があります。書き出し中は画面中央にオーバレイが出て**操作がロック**され、`Esc` でキャンセルできる旨と進捗が表示されます。尺ぶんリアルタイムで進みます。**Chrome 系**の利用を推奨します。
- **Compare (PiP)** で **Audio** が **Both** のとき、書き出し音声だけ LR を入れ替えます（**新しい方を L・古い方を R**）。画面では新しい方が全面・古い方が右下 PiP 窓のため、右側に映る古い方の音声を R に合わせる意図です。プレビュー再生の **Both** は「Audio」の説明どおり **古い方 L・新しい方 R** のままです。
- 書き出しは **Speed** 設定に関わらず常に **1.0×** で録画します。**Exp WebM** を押した時点で **Speed** 表示は **1x** に戻ります（書き出し後も **1x** のまま）。プレビュー再生も書き出し中は **1.0×** です。
- 本アプリの **Exp WebM** は、ブラウザの録画機能と Web Audio で得た音声（**Mute** 時は映像のみ）を組み合わせて、**WebM**（主に VP8 / VP9 系＋必要に応じて Opus）をその場で生成しダウンロードします。編集・納品の現場では **MP4**（H.264 等）や **MJPEG** など別形式に慣れている方も多く、WebM 単体では馴染みが薄い形式かもしれません。
- MP4 や MJPEG など**別コンテナへ変換**したい場合は、お手数ですがご利用の OS 向けの**動画変換ツールやエンコーダを別途ご用意**ください。本ページはサーバーにアップロードせず**ブラウザ内だけで完結**するアプリであり、ブラウザが直接書き出せる形式に出力が限られることは**仕様**です。
- WebM を他形式へ再エンコードするとき、**色空間・ガンマ・レンジ**（limited / full 等）の扱いをツール側で誤ると、結果が意図より暗くなったりコントラストがずれたりすることがあります。変換プリセットや「色の管理」「レンジ」の項目は、利用するソフトのマニュアルで確認してください。

### Seek / Jump などの画面上ヒント

- **Seek**・**Jump**・**Scrub** のほか、**Layout** / **Audio** / **Speed** / **Loop** / **Auto Play** の変更のあと、**画面上部に短いテキストのフラッシュ**が出ることがあります（表示ラベルは UI と同じ英語表記）。**ログ**とあわせて、直近の操作内容の確認に使えます。

### キーボードショートカット

- **Playback** / **Seek** / **Jump** / **Speed** / **Audio** / **Video** / **Loop** / **Auto Play** などにショートカットがあります。内容はページ中段の**キーボードショートカット**（**Playback**・**Speed**・**Seek**・**Jump**・**Audio**・**Video** の各カテゴリ）どおりです。**Speed** は **Slower** / **Faster** / **Reset 1x**（テンキー **−** / **＋** / *****、テンキー無しは **,** / **.** / **/**）です。
- **無効になるフォーカス**：`textarea`、`select`（**Video** のプルダウン含む）、`input` のうち**シークバー以外**、ならびに編集可能要素にフォーカスがある間は、ショートカットは処理されません。シークバーにフォーカスがある場合は、主要なショートカットキーを押すと**フォーカスが外れてから**処理されます。
- **矢印キー**は連打リピート時も **Seek** に使えます。その他の多くのキーはリピートを無視します。
